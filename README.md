# 西西文 · AI 产品手记

AI 产品经理个人作品集。包含开场视频、人物分层动画、项目画廊、职业经历和联系方式。

**[访问网站](https://xixiwen-ai-portfolio-release.vercel.app/)**

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm ci
npm run dev
```

浏览器打开 http://localhost:3000 。

```bash
npm test
npm run build
npm start
```

## 内容维护

- `src/data/portfolio.js`：个人资料与场景
- `src/data/resumeProjects.js`：项目内容
- `src/data/workExperience.js`：工作经历
- `src/data/personalResume.js`：简历
- `public/portfolio/`：视频、人物、项目封面
